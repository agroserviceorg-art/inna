# Inna Beauty — массаж спины

Одностраничный сайт-визитка: описание массажа, выбор длительности сеанса, галерея, отзывы и запись через Instagram-директ.

## Структура

- `index.html` — весь сайт (стили, скрипт и главное фото внутри одного файла)
- `images/` — папка для ваших фото галереи

## Что заменить перед публикацией

- В блоке «Атмосфера» заглушки «Здесь будет фото» → `<img src="..." alt="...">`
- В блоке «Отзывы» заглушки → настоящие отзывы клиентов
- Цены: сейчас написано «Стоимость уточняйте в личных сообщениях»

## Публикация на GitHub Pages

1. Settings → Pages
2. Source: Deploy from a branch, ветка `main`, папка `/ (root)`
3. Через минуту сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`
